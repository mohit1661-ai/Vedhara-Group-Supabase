# Place your video files here

Accepted formats: .mp4, .webm
Recommended max size: 15-20MB per file
Resolution: 1920x1080 or higher

## How to use

1. Copy your .mp4 files into this folder
2. Reference them in the hero components like this:

   ```tsx
   // In any page that uses VideoHeroSection or CinematicHero:
   <VideoHeroSection videoSrc="/videos/your-building-exterior.mp4">
     ...
   </VideoHeroSection>
   ```
